# Regression Tests

Every bug found while building Borderless, whether by a test, a review, the security check,
QA or a load or property test, was fixed the same way: first a test that fails on the old
code, then the fix. This page lists each bug and the test that now guards it. Test names are
quoted so you can find them with a search.

## Checks that keep new gaps from opening

- `test/api/route-sweep.api.spec.ts` reads `docs/openapi.json` and checks every route, one by
  one: 401 without credentials, 404 for someone else's wallet, 400 for a malformed ID, an
  empty body and a missing `Idempotency-Key`, 403 for a wallet key on session-only routes, 404
  for operator routes when no token is set, and 429 past the rate limit.
- After every full `yarn test`, the run fails if any documented route never answered with
  success. [api-test-coverage.md](api-test-coverage.md) lists every route with the statuses its
  tests produce.
- The mutation test fails CI if the money and retry tests stop noticing changes to the code.
